# TradingJournalApp

This repository contains a single-file React component: `TradingJournalApp.jsx`.

## Run in any React app

1. Create a React app (Vite / CRA / Next client component).
2. Copy `TradingJournalApp.jsx` into `src/`.
3. Render it from `App.jsx` or `main.jsx`.

```jsx
import TradingJournalApp from './TradingJournalApp';

export default function App() {
  return <TradingJournalApp />;
}
```

## Install dependencies

```bash
npm install react react-dom
```

Note: The component now uses internal lightweight chart primitives, so no external chart package is required.
